app.js — 12 lines to add billing 
const express = require("express");
const { createAnalyticsMiddleware } = require("api-analytics-middleware");

const app = express();

const analytics = createAnalyticsMiddleware({
  apiKeyHeader: "x-api-key",
  defaultRateLimit: 100,
  defaultWindowSec: 60,
  stripe: require("stripe")("sk_..."),
  stripeMeterId: "meter_123",
});

// Every request: authenticated, rate-limited, counted, billed
app.use(analytics.middleware);

app.get("/api/data", (req, res) => {
  res.json({ ok: true });
});

app.listen(3000);

What's inside

Three problems, one package

Most indie devs piece together three separate things to run a paid API. Candai bakes all three into one middleware you drop in and forget about.

🔒

Per-customer rate limiting

Define limits per API key, per window. Protect your backend from runaway consumers and give every customer a fair slice — no Redis required for dev.

📊

Real-time usage analytics

Track hits, volume, and patterns per customer. Read usage from headers on every response. Know who's active, who's churning, who's ready to upgrade — without a separate dashboard.

💳

Stripe metered billing

Connect Stripe and let usage drive the invoice. Candai records hits against a meter; Stripe handles the rest — prorating, invoicing, dunning. You just ship the API.

🔑

API key auth

Every request is checked for a valid API key before it touches your routes. Missing or invalid? Rejected instantly with a clear 401. No boilerplate in your handlers.

⚡

In-memory by default

Start tracking usage with zero infrastructure. Swap to Redis for production with one config change — same API, same behavior, just a different store.

📦

npm ready

npm install api-analytics-middleware. Works with Express 4.16+. Full test suite, CI on every push, versioned releases. Built to be depended on.

How it works

Three steps from zero to paid API

You don't need a billing team, a dashboard, or a Redis cluster. You need an Express app and about 15 minutes.

Step 01

Install & configure

npm install api-analytics-middleware. Pass your Stripe key, a meter ID, and your rate limit defaults. That's the whole setup.

→
Step 02

Mount the middleware

Call app.use(analytics.middleware) once. Every request is now authenticated, rate-limited, counted, and recorded against the Stripe meter — in that order.

→
Step 03

Ship and bill

Your API is live. Usage accrues against Stripe meters automatically. Customers get billed what they used. You get usage headers on every response. No billing code in your routes.
